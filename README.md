# 🌙 Сон и циклы

**Дневник сна, недосып, хронотип и калькулятор отбоя по 90-минутным циклам.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/sleep/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Калькулятор «во сколько лечь» и «во сколько встать»
- Недосып за неделю и регулярность режима
- Хронотип по середине сна
- Карта сна за две недели на SVG
- Личная норма сна по самочувствию

## Стек

JavaScript, SVG. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/sleep.git
cd sleep
python3 -m http.server 8000
```
